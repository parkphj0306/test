# ⚖️ 행정법원 판사 시뮬레이터 (법치의 수호자)

대한민국 행정법(행정법총론 및 행정구제법)의 핵심 판례와 원칙들을 판사가 되어 직접 판결하며 배우는 **인터랙티브 웹 게임**입니다.

---

## 📁 프로젝트 파일 구성

이 프로젝트는 별도의 서버나 빌드 도구 설치 없이 **웹 브라우저만 있으면 100% 독립적으로 구동**되는 정적 웹 애플리케이션(Static Web App)입니다.

| 파일명 | 역할 및 설명 |
| :--- | :--- |
| **`index.html`** | 게임 메인 UI 구조 (법원 헤더, 사건 기록부, 판결 선고대, 결과 모달, 판례 해설 창) |
| **`style.css`** | 대한민국 법원 감성의 기품 있는 인터페이스 디자인 및 반응형(모바일/PC 지원) 스타일 |
| **`game.js`** | 8개 핵심 대법원 판례 데이터베이스, 판결 판정 엔진, Web Audio API 무음원 법봉 타격 효과음 |
| **`README.md`** | 게임 설명 및 **로컬 실행 / 무료 웹 배포 완벽 가이드** |

---

## 💻 1. 로컬에서 바로 실행하는 방법 (1초)

1. 파일 탐색기에서 `c:\Users\동신대\Desktop\test` 폴더를 엽니다.
2. **`index.html` 파일을 마우스 더블 클릭**합니다.
3. 크롬, 엣지, 웨일 등 사용하는 웹 브라우저가 열리며 즉시 게임이 실행됩니다!

---

## 🚀 2. 웹 배포(Hosting) 과정 완벽 가이드

만든 웹 게임을 인터넷에 올려 **친구들에게 링크를 공유하거나 스마트폰으로 접속**할 수 있도록 하는 배포 방법 3가지입니다.  
모두 **완전 무료(Free)**이며, 이 프로젝트는 정적 파일(HTML/CSS/JS)이므로 매우 쉽게 배포할 수 있습니다.

---

### 방법 A: Netlify Drop (가장 쉬움, 1분 완료, 회원가입만 필요)
> 코딩이나 Git을 몰라도 **폴더를 마우스로 끌어다 놓기(Drag & Drop)**만 하면 즉시 전 세계에 배포됩니다.

1. **[Netlify 공식 홈페이지](https://www.netlify.com)** 에 접속하여 무료 회원가입(또는 GitHub/Google로 로그인)합니다.
2. 상단 메뉴에서 **Sites** 탭을 클릭합니다.
3. 화면 아래에 **"Want to deploy a new site without connecting to Git? Drag and drop your site output folder here"** 박스가 보입니다.
4. 바탕화면의 `test` 폴더(현재 이 폴더)를 통째로 해당 박스 위로 드래그 앤 드롭합니다.
5. 5초 뒤 전 세계 어디서든 접속 가능한 **나만의 고유 URL(예: `https://cool-court-game.netlify.app`)**이 즉시 생성됩니다!

---

### 방법 B: GitHub Pages (개발자 표준 방식, 포트폴리오용 추천)
> GitHub에 코드를 올려두면 자동으로 무료 호스팅 주소를 만들어주는 방식입니다.

1. **[GitHub](https://github.com)** 에 로그인 후 **New Repository**를 만듭니다 (예: 저장소 이름 `admin-law-game`, Public 선택).
2. 현재 `test` 폴더 안의 파일들(`index.html`, `style.css`, `game.js`, `README.md`)을 해당 GitHub 레포지토리에 업로드(Push)합니다.
   ```bash
   git init
   git add .
   git commit -m "행정법 게임 최초 커밋"
   git branch -M main
   git remote add origin https://github.com/당신의아이디/admin-law-game.git
   git push -u origin main
   ```
3. GitHub 저장소 화면 상단의 **Settings** 탭으로 이동합니다.
4. 좌측 메뉴에서 **Pages**를 클릭합니다.
5. **Build and deployment** 항목의 Branch를 `None`에서 **`main`** (또는 `/root`)으로 바꾸고 **Save**를 누릅니다.
6. 약 1~2분 후 `https://<당신의GitHub아이디>.github.io/admin-law-game/` 주소로 배포가 완료됩니다!

---

### 방법 C: Vercel 배포 (고성능, 원클릭 연동)
1. **[Vercel](https://vercel.com)** 에 가입 및 로그인합니다.
2. **Add New...** -> **Project**를 클릭합니다.
3. GitHub에 올려둔 `admin-law-game` 저장소를 선택하고 **Deploy** 버튼을 누릅니다.
4. 즉시 초고속 글로벌 CDN 주소가 생성되어 배포됩니다.

## ⚖️ 게임에 수록된 핵심 행정법 테마 및 판례

1. **신뢰보호의 원칙** : 폐기물처리업 사업계획 적정통보 후 주민 반대 민원에 따른 불허가처분 (대법원 97누12294)
2. **취소소송의 대상적격** : 일반 건축신고 반려행위의 행정처분성 인정 (대법원 2008두167 전원합의체)
3. **부당결부금지의 원칙** : 100cc 오토바이 음주운전으로 제1종 대형/보통면허 취소처분 (대법원 2011두29571)
4. **원고적격 (경업자 소송)** : 기존 시외버스 노선업자의 신규 노선연장 인가 취소소송 (대법원 2003두10738)
5. **행정행위의 하자 (당연무효)** : 납세고지서에 세액산출근거 미기재 처분의 중대·명백성 (대법원 97누183)
6. **행정대집행의 요건** : 건물 점유자의 비대체적 작위의무인 퇴거의무에 대한 대집행 계고 (대법원 97누4398)
7. **국가배상법 제5조 (영조물 하자)** : 고속도로 상 방치된 낙하물 사고와 도로관리청의 객관적 안전성 결여 (대법원 2004다45129)
8. **사정판결 (행정소송법 제28조)** : 위법한 도시계획 실시계획인가와 현저한 공공복리 침해 시 기각판결 (대법원 97누9757)
